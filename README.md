# KDM-Net Comparison Models

This repository contains the reimplementation code for the comparison models used in the KDM-Net experiments. These implementations were prepared for comparison under a unified experimental setting and are provided to support methodological inspection and further research use.

## Requirements

The code was prepared for Python 3.10+ and PyTorch. Install the required packages with:

```bash
python -m pip install -r requirements.txt
```

GPU acceleration is used automatically when a CUDA-enabled PyTorch installation is available.
